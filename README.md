# 私人档案库

完全离线的个人履历档案库：奖状证书、学习经历、工作与实习、技能证书、培训与学分、活动与讲座，统统收进来。

不登录、不联网、不上传，数据只在你自己的文件夹里。

## 先试试

直接打开 `最新版-私人档案库.html`（或从导航页点「打开」），内置演示数据，随便点。

> 浏览器里的改动只存在本机，刷新就回到演示；真实数据请用安装版。

## 下载

- **安卓**：`最新版-私人档案库.apk`（允许「安装未知来源应用」后安装）
- **Windows / Linux**：到 [Releases](https://github.com/Orangeting-here/Whimsical-Cookie-House/releases/latest) 下载
  - Windows：`…-Windows.zip`，整个文件夹解压后双击 `私人档案库.exe`
  - Linux：`…-Linux.tar.gz`，解压后 `chmod +x 私人档案库` 再运行

> 电脑版体积 120 MB+，超过仓库单文件上限，所以放在 Releases，不放在这个文件夹里。

## 数据在哪

- 电脑：程序旁边的 `档案数据/`
- 手机：`手机存储/Documents/<你的库名>/`

换设备时用「导出 / 备份」的 zip 互相导入即可。
