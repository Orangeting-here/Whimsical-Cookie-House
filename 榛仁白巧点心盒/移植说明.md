# 移植说明 · miniprogram-1 → 单文件 HTML

> 本文档说明微信小程序 `miniprogram-1` 全量迁移为单文件 `index.html` 的技术方案、
> 功能对照、被替换/降级部分与自检记录。配合《更新指南.md》使用。

## 1. 一句话结论

原小程序 **33 个页面（主包 7 + 21 个分包共 26 页）+ 1 个组件**（无云开发、无支付、纯本地逻辑）已全量迁移为
**一个 `index.html`（约 5.5 MB）**：双击即可在电脑浏览器打开，竖屏优先，
桌面横屏自动套用 响应式自适应布局（窄屏满宽、桌面最大 1200px 居中）。除 OCR 需联网下载引擎外，
其余功能全部本地运行，不依赖任何服务器。

## 2. 打开方式

| 方式 | 说明 | OCR 可用性 |
| --- | --- | --- |
| 双击 `index.html`（file://） | 即开即用，全部功能本地运行 | ❌ 浏览器禁止 file:// 加载跨源 Worker，OCR 页面会给出明确提示 |
| 本地服务器（`npx serve` / `python3 -m http.server`） | 推荐日常使用 | ✅ 首次识别时下载引擎与中文/英文语言包（约 31 MB），之后走浏览器缓存 |
| GitHub Pages | 公开托管 | ✅ 同上 |

## 3. 架构总览

单文件内嵌两套代码，构建期由 `build/build.js` 编排合成：

### 3.1 运行时四件套（浏览器里跑）

| 模块 | 职责 |
| --- | --- |
| `vfs.js` | 虚拟文件系统：IndexedDB 持久化 + 内存 Map + blob URL 缓存；隐私模式自动降级纯内存 |
| `core.js` | 小程序运行时：App/Page/Component/Behavior、虚拟 DOM diff/patch、setData 微任务批量渲染、hash 路由、组件隔离、触摸事件桥接 |
| `ui.js` | 交互层：toast / modal / actionSheet / loading / picker 自绘实现 |
| `wx-api.js` | 微信 API 兼容层：约 80 种 `wx.*` API 的浏览器等价实现 |

### 3.2 构建四件套（Node 里跑，产出 dist/index.html）

| 脚本 | 职责 |
| --- | --- |
| `wxmlc.js` | WXML → 模板函数（wx:for / wx:if / 事件绑定 / 表达式编译） |
| `wxssc.js` | WXSS → CSS（rpx → `calc(var(--rpx)*N)`，`page` 选择器 → `.app-root`） |
| `packer.js` | CommonJS → 模块表（含 npm 映射、回调式 require、当前页面路径注入） |
| `build.js` | 编排：源码扫描 → 编译打包 → 资源内联 → 合成 index.html |

### 3.3 第三方库处理

| 库 | 处理方式 |
| --- | --- |
| tesseract.js 主库（66 KB） | 内嵌进单文件 |
| tesseract.js worker / wasm 核心 / 中英语言包 | CDN 懒加载（jsdelivr），首次识别时下载 |
| pdfjs / pdflib / qbsplit / threejs-miniprogram | 随业务代码打进模块表 |
| kgm-v2-mask.bin（337 KB） | base64 内联进 `__ASSETS`，启动时写入 VFS |

## 5. 微信 API → 浏览器 API 对照（核心映射）

| 类别 | 微信 API | 浏览器等价实现 |
| --- | --- | --- |
| 存储 | wx.getStorageSync / setStorageSync | localStorage + VFS 统一封装（safe-storage 语义保留，空串视为无值） |
| 文件 | wx.getFileSystemManager | VFS（IndexedDB + 内存 + blob URL），路径语义不变 |
| 路由 | wx.navigateTo / redirectTo / navigateBack / reLaunch / switchTab | hash 路由，**success/fail/complete 三回调语义完整还原** |
| 页面渲染 | setData / Component / Behavior | 虚拟 DOM diff + 微任务批量渲染 |
| UI 交互 | wx.showToast / showModal / showActionSheet / showLoading | 自绘 UI（样式对齐小程序视觉） |
| 选择器 | wx.createSelectorQuery | DOM 实现，支持 .select().node()/.boundingClientRect() 链式与 .in(组件) |
| 媒体 | wx.chooseMedia | input[type=file] + FileReader |
| 画布 | wx.createCanvasContext | HTML5 Canvas 2D |
| OCR | wx.createVKSession({track:{OCR}}) | tesseract.js（详见 §6） |
| 视频抽帧 | wx.createVideoDecoder | `<video>` + canvas 逐帧解码 |

## 6. OCR 适配（wx.createVKSession → tesseract.js）

- 保留原会话契约：`on('updateAnchors'/'addAnchors'/'error')`、`start(cb)`、`runOCR({frameBuffer,width,height})`、`stop/destroy`，业务代码**零改动**。
- 引擎与语言包走 jsdelivr CDN 懒加载（chi_sim 约 20 MB + eng 约 11 MB），首次识别耗时取决于网速，之后浏览器缓存。
- 限制：浏览器端**不支持摄像头实时 OCR**（mode:1 明确报错）；静态图识别（mode:2）完整支持。
- file:// 双击打开时无法加载 OCR 引擎，会弹出提示引导改用本地服务器或 GitHub Pages——其余功能不受影响。

## 8.5 浏览器适配要点（第二轮复核新增）

- **scroll-view 原生滚动**：小程序 scroll-view 由组件原生滚动，浏览器端统一在运行时给
  `scroll-y` / `scroll-x` 元素加 `overflow: auto`（含无值布尔属性），页面滚动与小程序一致。
- **组件内部事件**：修复组件边界拦截在捕获阶段 stopPropagation 导致组件内按钮（如导航栏
  返回/首页键）全部失灵的问题——改为冒泡阶段拦截，组件内点击正常、事件不穿透到页面。
- **组件方法作用域**：makeScope 增加 `methods` 包解析并绑定组件实例（返回键 handler 修复）。
- **全局 API 对齐**：暴露 `getCurrentPages()` / `getApp()` 到 window，与小程序一致。
- **导航栏返回**：`back=true` 未传 delta 时默认回退 1 层（源补丁，已写回源码）。
- **微信能力清理**：删除全部「从微信聊天记录导入」入口（file-io 菜单、图片转换×3、OCR、
  PDF 转换、NCM、火柴人动作导入菜单），浏览器版来源仅保留本地文件/相册/剪贴板。

- **内联样式 rpx 换算**：小程序内联样式支持 rpx（如鱼缸水球 `width:135rpx`），浏览器不认 →
  运行时统一换算为 `calc(var(--rpx)*N)`。修复后水球恢复正圆、阴影/尺寸全部生效。
- **picker-view 滚轮**：小程序原生滚轮 → 浏览器为「裁切列 + 上下渐变遮罩」的静态滚轮
  （计时器时/分/秒、时间计算年月日均生效），不再整列文字倾倒。
- **文案全量清洗**：全盘扫描 JS/WXML 中用户可见的「微信」「手机」字样并替换为桌面口径
  （导入来源、OCR 提示、计时器说明、视频倍速、音频解码、导出菜单、备份说明等），
  仅保留代码注释与「微信小程序」来源说明。

## 8.6 运行时健壮性修复（第三轮代码审核）

外部审核报告逐条处理后的改动，全部在 `runtime/`、`build/`、`embed/` 层，未动业务代码：

- **触摸事件透传**：`makeEvent` 原先丢弃 `touches/changedTouches`（恒为空数组），导致轮播拖动、
  便签拖拽、水球、火柴人交互等 15+ 处手势在浏览器端失效。现按原生 `TouchList` 转普通数组透传，
  合成事件自动补单点。
- **长按监听泄漏**：`contextmenu` 用匿名函数无法移除、pointer 三件套未进 cleanup —— 改为具名函数并入清理列表。
- **清除缓存补 VFS**：`clearLocalFiles` 递归删除 `filepool` 目录；用户确认弹窗已声明会清空导入文件。
- **输入框回写保护**：`input` / `textarea` 只在「模板里的 value 本身变了」时才回写 DOM，焦点中绝不覆盖用户输入
  （修复未绑 value 的输入框每帧被清空、以及「只能输入一个字母」）。
- **diffChildren 免重排**：子节点顺序未变时完全跳过 DOM 移动（输入框不失焦、音视频不中断）；key 复用校验标签类型。
- **slot 常驻**：`mountSlots` 不再销毁 holder，改 `display:contents` 常驻 + 结构指纹比对重建，动态 slot 可更新。
- **sw.js 真后台更新**：缓存命中后静默 revalidate，`install` 加 `skipWaiting()`。
- **wx.request**：GET/HEAD 的 `data` 拼 query、`abort()` 走 AbortController、支持 `responseType:'json'`。
- **hash 深链**：启动时解析当前 hash 命中页面即直达；栈外路径回落首页并修正地址；畸形 hash 不抛异常。
- **相册/保存**：`saveImageToPhotosAlbum` 等检查下载结果，失败走 `fail` 并补 `complete`。
- **主题监听**：`onThemeChange` 单例派发，`offThemeChange` 在监听清空时移除 MQL。
- **embed.js**：`message` 只认壳内 iframe 的 `source`（伪造消息关不掉）；补 `@media` 缺失的闭合花括号，
  `prefers-reduced-motion` 在桌面端恢复生效。
- **备份导入**：拒绝 `..`、绝对路径、空字节等危险路径，过滤 `__proto__` 类键名。
- **备份加密**（`common/backup-crypto.js`）：
  - 自动快照始终用**本机随机密钥**（AES-256-GCM，密钥存原生 localStorage `bk_dev_key_v1`，不进 `mp_*` 命名空间、
    不进备份、不被「清除缓存」扫到）加密后落盘 —— 同浏览器其他扩展/使用者直接打开快照 JSON 也看不到患者床号；
  - 手动导出时在备份弹层填「导出口令」即用 **PBKDF2-SHA256(150k) + AES-256-GCM** 加密，口令随文件走、换机可解；
    不填则明文，但勾了「病程病历（查房）」会先弹确认提醒；
  - 导入/回滚自动识别明文与加密外壳：加密文件缺口令提示 `NEED_PASSWORD`、口令错提示 `BAD_PASSWORD`；
  - 环境无 WebCrypto 时自动降级明文并提示，不阻断导出。
- **password 属性**：小程序 `input` 的布尔 `password` 编译后落在 attrs 里，运行时现将其映射为 `type=password`
  （只在创建时设置，避免运行中改 type 清空已输入内容）。

36. PDF 加密「自洽但不通用」（用户实锤的笑点级 bug）：加密后导出的文件，在自己工具里用同一密码能解开，拿到 WPS / Acrobat / qpdf 里却提示「密码错误」。根因在 `padBytes`：标准要求把密码补到 32 字节时拼接 PAD 的**前 (32-n) 个字节**，实现写成了 `PW_PAD.subarray(t.length)`，等于跳过前 n 个 PAD 字节、尾部补 0。加解密两边用同一个错误 PAD，所以内部完全自洽；任何标准阅读器用正确 PAD 派生密钥，必然对不上。修复：`padBytes` 改为 `PW_PAD.subarray(0, 32 - t.length)`；同时新增 `legacyPadBytes` 与 `padPassword(pw, utf8, legacy)`，`validatePassword` 依次尝试 标准 Latin-1 / 标准 UTF-8 / 旧版 Latin-1 / 旧版 UTF-8 四种 PAD，**让本工具历史上加密的 PDF 仍能解开**。验证：pikepdf（qpdf 内核）用密码可打开新产物；旧产物用新代码可解密；pikepdf 生成的 AES-128 加密 PDF 可被工具解密、错误密码正确报错；浏览器内实测加密 / 解密同样通过。

## 11. 已知限制

- OCR 首次使用需联网（引擎 + 语言包 CDN 下载）；完全离线 OCR 需额外内嵌约 35 MB 资源，本版按约定不内嵌。
- 视频抽帧链路（`createVideoDecoder`）已实现，但未用真实视频做端到端验证，首次遇到异常请反馈。
- `picker-view` 滚轮（计时器时长选择）暂为静态渲染，请用下方手动输入框或 6 个快捷预设设定时长。
- 火柴人页使用 WebGL（three.js），需要浏览器支持且未禁用 GPU。
- 桌面端无摄像头场景，实时 OCR 明确不支持。
- 浏览器 localStorage 有 5 MB 上限；大文件走 VFS（IndexedDB），隐私模式下退化为内存、刷新即失。
- **自动备份快照已加密**：快照含查房记录，落盘前用本机随机密钥做 AES-256-GCM 加密（保留 7 天、不上传）。
  代价是密钥只在本浏览器：清除浏览器站点数据后旧快照无法解开；快照也不能直接拷到别的设备用，
  跨设备迁移请走「导出备份 + 口令」。
- **手动导出的隐私边界**：填了口令才是密文；不填则为明文 JSON（勾选查房分组时会二次确认）。
  明文文件一旦外发无法收回，请自行判断。
- **NCM/KGM 解密模块**按原样保留（主页不展示、需手动进入）。该功能涉及音乐平台加密格式，
  托管在公开 Pages 上存在被投诉下架的可能，是否保留/独立分发请自行权衡。
- **游戏签到模块已整体移除**（连同两份第三方许可证），与 README「不联网签到」口径一致。
