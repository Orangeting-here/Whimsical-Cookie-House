# 🍪 Whimsical Cookie House · 奇思妙想饼干屋

> 一只装着 30 个小工具的手工饼干罐，烤好装进一个 HTML 文件里啦！
> 双击打开就能吃（用），不需要服务器，不需要安装，连微信都不用～ ✨

## 🏡 这是什么

原本是一个微信小程序的**全部核心功能**，被小心翼翼地搬进了一个
**单文件 `index.html`**（约 5.5 MB）：

- 🗓️ 首页小想法中心：日历、查房记录、待办清单、随手贴便签
- ⏱️ 效率组：计时器、时间计算、待办
- 📄 文件组：图片转换、PDF 转换 / 阅读 / 生成 / 文字提取、文档转换、表格转换、Markdown 转换、
  **PPT 图片提取与每页转图（含讲义排版）**、QBS 分割
- 🎵 影音组：音乐播放器、视频播放器（含抽帧）
- 🧠 学习组：题库、文件池、OCR 图片转文字（中英双语）、火柴人动画演示
- 🔐 其他：NCM 解密、统计、格式支持总表、许可页

### 🆕 桌面工作台与本批更新

- **转换工作台** 🔀 首页最上方新增入口：只分三大类——**图片 / 文档 / 压缩包**。
  「文档」是一大类，里面再分 PDF · Word · 表格 · 文本 · 演示（PPT）五个小节（PDF 不再和「文档」并排）。
  右栏立刻列出这一类**真能做的转换**，点一下直达模块并预选好目标格式；桌面可直接把文件拖进来，
  按扩展名自动命中类型（提示会说「属于文档 · PDF」）；右栏标题下还有一排小节胶囊（PDF / Word / 表格 / 文本 / 演示），点一下直接定位到对应分组。做不到的格式（WebP 编码、XLSX 解析）标灰写明原因。
- **PPT 图片提取** 🖼 PPTX 本质是 zip：直接读 `ppt/media` 目录，把里面所有图片原样取出来（不重新压缩），
  grid 里可逐张勾选、全选，多张自动打成一个 zip；单张直接存盘。
- **PPT 每页转图** 📄 按幻灯片比例重绘每一页成 PNG（1280 / 1600 / 1920 三档宽度），
  也可按讲义排版合成一张：一页放 1 / 2 / 4 / 6 张，2 页时自动铺满一行，画布高度跟着版式缩，不留大白边。
  原平铺在首页的 7 个转换模块已收进工作台，首页只留这一条主路径；图片转文字（OCR）等非转换工具仍留在列表。
- **导入少点一次** 👆 只有一个来源时不再弹「从本地文件导入」选择框，点一下就进文件选择器。
- **桌面工作台壳层** 🗂 工具宫格提到首屏，左侧常驻导航（工具 / 今日 / 任务 / 设置），宽屏按屏吸附；单一模块的分组不再显示二级标题。
- **今日屏水球** 🫧 待办水球按紧迫度变色（逾期红 / 临近琥珀 / 等级青蓝，病历清单薄荷绿），数量徽章显示真实总数，缸内最多画 6 颗、超出标 `6+`。
- **日夜自动主题** 🌗 默认跟随时间：6:00–18:00 浅色软陶，其余时段深色玻璃；可在设置里手动锁定外观，锁定后不再随时间变化。
- **音视频编码预检** 🎬 导入时按 `canPlayType` 先探一遍编码，浏览器解不了的格式提前给出提示，不再黑屏。
- **格式支持总表** 📋 按图片 / 文档表格 / 音频 / 视频 / 压缩包列出各格式档位（原生离线 / 内置解析 / 需联网 wasm 预留 / 暂不支持）。
- **备份可加密** 🔐 自动快照含查房记录，落盘前用本机随机密钥 AES-256-GCM 加密（其他扩展直接翻 IndexedDB 也看不到床号）；手动导出时在备份弹层填「导出口令」即生成密文文件（PBKDF2 派生 + AES-256-GCM），换机导入填同一口令即可，不填仍是明文并会二次提醒。
- **运行时报错修复** 🩹 触摸事件透传（滑动手势恢复）、清除缓存连带清空文件池、「清除缓存」不再漏掉 VFS、输入框打字不再被重渲染吞掉、hash 深链可直达页面、SW 后台静默更新。

### 🧩 早先长出来的三样东西

- **能力跟着机器长** 🫧 打开后先跑一次 0.1 秒的体检（算力 / 内存 / 多线程 / wasm），
  然后按这台机器的真实分数决定一次处理多少张、PDF 一批渲染几页。
  弱机不会少功能，只是更稳更慢；强机自动放开。设置里能看到「本机能力」面板。
- **任务中心** 🗂 每次转换 / 导出 / 识别都会记一笔：做了什么、多少件、用了多久。
  跑到一半被关掉的会标成「已中断」——不是假装没发生，而是让你知道它跑到哪了。
- **能嵌进你的导航页** 🪄 一个 `embed.js` + 一行 `onclick`，就能让它以全屏 App 的形态
  从你的单文件导航页里点开，自带「← 返回导航页」，不用另开标签页；嵌入时内部标题栏自动收成一条返回键，不和导航页顶栏叠两层。

**纯本地运行**：文件都存在你自己的浏览器里（IndexedDB），不上传任何东西。
唯一会联网的情况：OCR 识别引擎与中英语言包首次使用时自动下载。

> 窄屏/手机上则自动全屏，双向舒适～

## 🧱 技术栈

- 手写小程序运行时（虚拟 DOM + setData 批量渲染 + hash 路由）
- WXML/WXSS 编译链（rpx 自动换算）
- 约 80 种 `wx.*` API 的浏览器等价实现
- OCR：tesseract.js；PDF：pdf.js / pdf-lib；3D：three.js

完整技术说明见 [移植说明.md](移植说明.md)，更新流程见 [更新指南.md](更新指南.md)。
