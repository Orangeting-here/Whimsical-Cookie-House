# 词频分析器

一个**单文件、完全离线、双击即用**的中文高频字词分析工具。导入 TXT 即可统计字词频率、查用词重复与套路，也可以当作语料热词统计器使用。适合分析小说、访谈、录音转写稿等中文文本。

整个工具就是一个 `词频分析器.html`（约 2.5 MB），词典内嵌在文件里，**不依赖任何服务器、外部资源或网络连接**。

## 功能特性

- **内嵌 34.9 万条 jieba 开源词典**：中文自动分词，支持自定义词、整词优先切分
- **七个分析视图**
  - 概览：字数、词元、句数、段落等统计卡片，高频词 Top 榜与洞察提示
  - 词频榜：完整词频列表，支持搜索、词性/长度/分类筛选、多种排序
  - 短语重复：自动统计 2–4 字重复短语与 PMI 关联度
  - 部位 · 动作：8 个词桶（头面、颈肩、躯干腰背、四肢手足、皮肉骨骼、生理体征、体态动作、手部动作），专查小说里的身体描写套路
  - 出处：任意词/短语的全部上下文定位，带章节信息与分页
  - 对照分析：与通用汉语基准对比，并支持加载自己的参照语料做 keyness 分析（G² 对数似然比 + 倍数）
  - 词库：候选词管理、自定义词、排除词、词表导入
- **多文档批量处理**：一次选多个文件或整个文件夹，多篇合并成一份语料统计总数，也可随时追加、移除单篇
- **编码自动识别**：支持 UTF-8、GBK、UTF-16（LE/BE，含无 BOM）、Big5；识别不准可手动点标签切换编码重读
- **词条合并**：人名/专名被切碎时（如「艾尔海森」被切成碎片），勾选碎片即可合并为整词并重新计算
- **榜单行内删除**：永久排除（写本地存储）或临时屏蔽（仅内存，刷新即恢复）
- **去数字、去虚词开关**：数字不再混入词榜
- **结果可复制、可导出**：TSV 复制，CSV / JSON 下载，导出内容跟随当前筛选条件

## 使用方法

### 本地使用（推荐）

1. 下载本仓库的 `词频分析器.html`
2. 双击用任意现代浏览器（Chrome、Edge、Firefox、Safari）打开
3. 点「导入 TXT」选择文件，或直接把文件/文件夹拖进页面；也可以先点「载入示例」体验
4. 在各视图间切换查看结果，需要时复制或导出

### 在线使用

如果仓库开启了 GitHub Pages，可直接访问（地址见仓库右侧 Pages 提示）：

```
https://<用户名>.github.io/<仓库名>/词频分析器.html
```

即便通过在线地址打开，所有分析仍在你自己的浏览器本地完成，文本不会上传到任何地方。

## 隐私说明

- **完全离线**：代码中没有任何网络请求（无 fetch、XHR、WebSocket、外部图片或脚本），可在断网环境使用
- 导入的文本只在浏览器内存中解析，**不发送、不保存到服务器**
- 自定义词、排除词等个人设置仅保存在浏览器本地存储（localStorage）中，清除浏览器数据即可全部移除
- 页面不含任何作者信息、统计埋点或跟踪代码

## 技术说明

- 纯原生 HTML + CSS + JavaScript，零第三方运行时依赖、零构建步骤
- 词典以 deflate-raw 压缩后 base64 内嵌；优先使用浏览器原生 `DecompressionStream`，并自带纯 JavaScript inflate 实现为旧浏览器兜底
- 大文本采用分页处理 + 进度回调，避免界面卡死
- 支持的文本规模：常规百万字级文本可在数秒内完成；超大语料（1500 万字以上）受浏览器内存限制，建议分批处理；超大语料的短语统计基于前 150 万词元（页面内有标注）
